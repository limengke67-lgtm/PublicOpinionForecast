# PublicOpinionForecast · 舆情预测

基于 [MiroFish](https://github.com/666ghj/MiroFish) 扩展的毕业设计研究系统，保留原作者署名和 AGPL-3.0 许可证。

项目以“事件任务”为主入口，把资料、知识图谱、角色推演、预测冻结、真实观测验证、自适应更新和综合报告关联起来。三个研究方向为预测验证、降本提速、真实观测驱动的滚动预测。

## 启动

```powershell
npm run doctor
npm run dev:research
```

打开 http://127.0.0.1:3000/，先点击“体验完整合成流程”。此模式无需模型和 Zep 凭据，不调用付费模型。首次安装步骤见 [README](README.md)。

Docker 交付使用 `docker compose up --build`，访问 http://127.0.0.1:5001/。默认构建当前项目源码并启动本地研究模式，不会下载上游项目的旧镜像来冒充本项目。

完整在线推演沿用 `.env.example` 的配置。凭据后续补齐；开启在线模式并配置用量限制后，再进行真实多智能体试跑。

## 验收与边界

运行 `npm run verify` 检查后端业务测试和前端构建。真实历史数据回放、合成数据测试、模拟外部接口的端到端测试与真实在线推演分别记录，不能相互替代。

自适应数值层的历史回放尚未普遍优于最近值基线。完整数据、协议和结果保留在仓库中，不将软件完成度或模块测试数当作真实预测准确率。
